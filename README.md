# fly-brain-minecraft

Мозг дрозофилы управляет мухой в Minecraft. 2531 нейрон с настоящими связями
из коннектома FlyWire работает как спайковая сеть и сам решает, что делать:
замечает надвигающегося моба или игрока, выбирает, в какую сторону уходить,
взлетать или уходить пешком, когда успокоиться и сесть. Поток воздуха от
движущихся существ муха чувствует антеннами, а голодная ищет еду по запаху.

Кроме одиночной мухи есть гонка нескольких мух и опыты над мозгом: пестицид,
алкоголь, синестезия. Активность всех нейронов можно записать и нарисовать
в 3D по их настоящим координатам в мозге.

## Как устроено

Мост 10 раз в секунду опрашивает сервер по RCON: кто вокруг, какой рельеф,
где еда, сколько у тела здоровья. Из этого получаются частоты сенсорных
нейронов: зрительных детекторов надвигания (LC4, LPLC1, LPLC2), джонстонова
органа в антеннах и обонятельных рецепторов. Мозг считает все 2531 нейрон
с шагом 0.1 мс, а с нисходящих нейронов, которые у настоящей мухи передают
команды из мозга в тело, снимается команда: куда уходить, насколько быстро,
прыгать ли вверх. Двадцать раз в секунду по этой команде двигается тело в
игре.

Код разделён на три пакета: `flybrain` - сам мозг, он ничего не знает про
игру; `flygame` - тело мухи и её поведение в мире; `mcworld` - связь с
сервером. Чтобы подключить мозг к другой игре, достаточно написать свой мост.

## Установка

Все команды - из корня проекта.

### 1. Python и библиотеки

Нужен Python 3.11 или новее.

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate      # Mac/Linux
pip install -r requirements.txt
```

Ставятся numpy, scipy, pandas, matplotlib и mcrcon.

### 2. Схема мозга

Схема собирается из коннектома FlyWire FAFB v783. Зайдите на
[codex.flywire.ai](https://codex.flywire.ai), войдите через Google, примите
условия и выгрузите через Info → Download Data в `data/raw/`:

- `consolidated_cell_types.csv.gz`
- `classification.csv.gz`
- `connections_princeton.csv.gz`
- `coordinates.csv.gz` - нужен только для 3D-картинки мозга

Затем один раз:

```bash
python tools/extract_circuit.py
```

Получится `data/circuit.npz` - всё, что нужно дальше. Сами CSV в репозиторий
не кладутся. Сборка читает файл связей кусками и занимает пару минут.

### 3. Сервер Minecraft

Нужен сервер Minecraft Java Edition. Проверялось на 26.2 - ему нужна Java 25.

1. Скачайте `server.jar` с [minecraft.net](https://www.minecraft.net/download/server)
   в отдельную папку и запустите:
   ```bash
   java -Xmx4G -jar server.jar nogui
   ```
   Первый запуск остановится и создаст `eula.txt` - поставьте в нём
   `eula=true` и запустите снова.
2. Остановите сервер (`stop`) и включите RCON в `server.properties`:
   ```
   enable-rcon=true
   rcon.port=25575
   rcon.password=flyproject
   ```
   Если меняете порт или пароль - те же значения в `mcworld/constants.py`
   (`RCON_PORT`, `RCON_PASSWORD`) и в начале `demos/rcon_probe.py`.
3. Запустите сервер и зайдите на него клиентом той же версии: Сетевая игра →
   Прямое подключение → `localhost`.

### 4. Проверка

```bash
python demos/rcon_probe.py                    # связь с сервером: вы должны быть в игре
python demos/minecraft_bridge.py --simulate   # мост без сервера
python demos/minecraft_bridge.py --spawn      # муха появится перед вами
```

## Как собирается схема

Вручную задаются только якоря - нисходящие нейроны, которые командуют телом:
`DNp01` (гигантское волокно), `DNp02`, `DNp11` - побег, и `DNb05` - руль. Всё
остальное втягивается обходом графа:

- **назад от якорей:** все нейроны, которые дают на них хотя бы 10 синапсов
  (`--min-synapses`, `--hops`);
- **вперёд от рецепторов**, которые сами до якорей не дотягиваются (обоняние,
  влажность, температура): на шаг вперёд (`--forward-hops`), иначе они
  повисли бы входом в никуда;
- сенсорные типы добавляются целиком.

В итоговую матрицу идут пары нейронов с 5 синапсами и больше.

Что получается сейчас (`python tools/inspect_circuit.py`):

| группа                  | нейронов | типы                                                |
| ----------------------- | -------- | --------------------------------------------------- |
| зрение                  | 454      | LC4 104, LPLC1 140, LPLC2 210                       |
| механосенсорика         | 393      | джонстонов орган: JO-A 94, JO-B 299                 |
| обоняние                | 377      | ORN_V, DA2, DM1, DM2, VA2, DM4, DM5                 |
| влажность и температура | 103      | HRN_VP1d, VP1l, VP4, VP5, TRN_VP1m, VP2, VP3a, VP3b |
| промежуточные           | 1196     | втянуты обходом                                     |
| выход                   | 8        | DNp01, DNp02, DNp11 (побег), DNb05 (руль), по паре  |

Возбуждающих 2046, тормозных 458, без знака 27. Связей 46 028.

Знак связи: ацетилхолин +1, ГАМК и глутамат −1, остальные медиаторы 0.

## Без игры

Маленький учебный пример: 20 детекторов надвигания и гигантское волокно,
данные не нужны:

```bash
python demos/minimal_lif.py
```

Эталонный прогон на настоящей схеме: объект летит на муху по формуле,
на выходе - график и время срабатывания гигантского волокна:

```bash
python demos/looming_offline.py --azimuth -40   # слева: срабатывает
python demos/looming_offline.py --azimuth 180   # сзади: молчит, глаза не видят
```

Сзади зрение молчит. В игре такую угрозу ловит джонстонов орган: поток
воздуха от движущегося моба (в оффлайн-прогоне его нет).

Азимут в `--azimuth`: 0 спереди, −90 слева, +90 справа.

## Minecraft

### Запуск

```bash
python demos/minecraft_bridge.py --spawn          # создать муху перед игроком
python demos/minecraft_bridge.py                  # муха уже есть в мире
python demos/minecraft_bridge.py --simulate       # без сервера, самопроверка
```

Без `--spawn` мост ищет в мире сущность с тегом `flybrain`. Если её нет,
он напечатает команду `/summon`, которой её создать. Ctrl+C - выход.

Мост выключает в мире правила `send_command_feedback` и `log_admin_commands`
(до Java 1.21.11 они назывались `sendCommandFeedback` и `logAdminCommands`,
мост пробует оба имени), иначе чат и лог сервера тонут в его командах - это
десятки строк в секунду. Обратно правила он не включает. Вернуть:
`/gamerule send_command_feedback true` и `/gamerule log_admin_commands true`.
Или запускать с `--keep-feedback`.

При старте мозг калибруется (около минуты): подбираются множитель синапсов,
фоновый шум и пороги. На текущей схеме это GAIN 0.0460, шум 10.6 Гц, фон на
выходе 24.2 Гц, возбуждение покоя 0.39, посадка ниже 0.49, взлёт от 0.71.

Полный список - `--help`. Основные:

| ключ                                     | по умолчанию        | что делает                                                                               |
| ---------------------------------------- | ------------------- | ---------------------------------------------------------------------------------------- |

| `--seed N`                               | случайное           | зерно шума нейронов; печатается при старте, чтобы прогон можно было повторить            |

| `--invulnerable`                         |                     | тело неуязвимо                                                                           |

| `--floor N`                              | 6                   | на сколько блоков ниже старта может опуститься полёт                                     |
| `--speed N`                              | 9                   | скорость полёта при полной тяге, блоков/с                                                |
| `--hunger N`                             | 0                   | голод на старте, 0..1                                                                    |

в `flygame/constants.py`, числа сервера - в `mcworld/constants.py`.

### Строка состояния

```
[ 245.6s] Chicken#2    1.1 бл   +7°  LC   0.0 Гц ветер   0.0  DN L 54.4 R 27.0  уход  +17° возб 0.51 [#####.....]  1.8 бл/с голод 0.33 запах 13.7- вниз идёт      [не видит: player]
```

- ближайшее существо, расстояние и азимут;
- `LC` - самая высокая частота среди зрительных нейронов, `ветер` - среди
  нейронов джонстонова органа;
- `DN L / R` - суммарная частота левых и правых нисходящих нейронов;
- `уход` - угол ухода, `возб` - накопленное возбуждение, полоска - тяга;
- скорость, голод;
- `запах` - уровень с антеннальной доли и куда он меняется (`^` растёт, `v`
  слабеет, `-` ровный), `вниз` - запаху разрешено сажать муху;
- состояние: в полёте, снижается, сидит, идёт, ест, оглушена;
- `ищет рядом` - локальный поиск после еды, `[не видит: …]` - включён `--ignore`.

Раз в 10 секунд - строка `КОМАНДЫ`: сколько команд в секунду уходит на сервер
и, главное, «опрос N Гц из 10». Если опрос проседает, тормозит сервер.

### Гонка

Несколько мух в одном мире, у каждой свой мозг в своём процессе:

```bash
python demos/race.py --fly a:bee --fly b:chicken --fly c:bat
python demos/race.py --fly a:allay:10,70,0,90 --fly b:bat:10,70,4,90 -- --hunger 0.6
```

`--fly ИМЯ:ТЕЛО[:X,Y,Z,YAW]`; без координат мухи встают в ряд перед игроком.
Всё после `--` уходит каждой мухе. `--own-food` - у каждой свой вид еды,
чтобы не съедали куски соперниц. Вывод мух - в `output/race_ИМЯ.log`.

## Поведение

Отдельного кода для «покоя» и «побега» нет: тело всегда ведётся одним
сигналом. Когда смотреть не на что, работает только фоновый шум нейронов, и
муха дрейфует. Когда что-то надвигается, активность подскакивает.

- **Пороги** - множители к возбуждению покоя, замеренному при старте: ниже
  ×1.25 три секунды - садится; выше - уходит пешком; выше ×1.8 или при рывке
  гигантского волокна - взлетает.
- **Неподвижный моб не пугает:** LC4 и LPLC2 - детекторы надвигания, а не
  присутствия.
- **Повороты** - рывками, как у настоящей мухи.
- **Голод** на мозг действует только через вход: голодная суетливее (выше
  фоновый шум сенсорных нейронов) и смелее (вход от угрозы ослаблен до ×0.4
  при полном голоде). При голоде от 0.98 тело получает урон раз в 8 секунд.
- **Еда.** Пахнут выпавшие предметы в радиусе 32 блоков. Ест только на земле
  и при голоде от 0.2: ломтик арбуза, яблоко, сладкие и светящиеся ягоды,
  тыкву. Блоки арбуза и тыквы кусает и раскалывает, куст ягод объедает.
- **Поиск.** По градиенту запаха и разнице между антеннами; над сильным
  запахом голодная садится сразу. После еды - 25 секунд локального поиска.
  Помнит до 5 мест, где ела (путевая интеграция с накоплением ошибки), и
  возвращается к ним голодной. Без запаха и памяти - расширяющиеся прямые
  пробежки.
- **Вода и лава:** не садится; оказалась на воде - взлетает.
- **Удар:** рана обостряет чувство угрозы и забывается за 90 секунд; сильный
  удар оглушает - муха падает вверх ногами.

## Запись и картинка мозга

```bash
python demos/minecraft_bridge.py --record output/tape.npz
python tools/render_brain.py output/tape.npz      # кадры в output/brain/
```

`render_brain.py` раскладывает нейроны по их настоящим координатам в мозге и
подсвечивает работающие. Координаты попадают в `circuit.npz`, если при сборке
в `data/raw/` лежал `coordinates.csv.gz`. Из того же файла рисуется силуэт
мозга вокруг (`--no-context` - без него).

## Опыты над мозгом

`demos/brain_lab.py` запускает обычный мост и делает операцию над мозгом
после калибровки (до неё калибровка подкрутила бы всё обратно). Мост и
одиночная муха не меняются.

```bash
# без игры: мозг и пороги поведения при разных дозах
python demos/brain_lab.py --drug pesticide --offline
# в игре: 30 с трезвая, потом за 3 минуты доза дорастает до полной
python demos/brain_lab.py --drug pesticide -- --spawn --record output/pest.npz
python demos/brain_lab.py --drug alcohol --dose 0.8 --ramp 2 -- --spawn --record output/alc.npz
# картинка в обычных цветах; оранжевые - сильнее, чем трезвая, фиолетовые - слабее
python tools/render_brain.py output/pest.npz --vs-sober
```

- **Пестицид** - ацетилхолиновые синапсы сильнее (фосфорорганика не даёт
  убрать ацетилхолин из синапса). Муха не может усидеть, потом носится без
  остановки; мозг разгорается. Через 20 с полной дозы - паралич
  (`--paralysis`): тело переворачивается и падает, мозг работает дальше.
- **Синестезия** (`--synesthesia`) - новые связи в мозге: 4 нейрона
  обонятельной доли, которые молчат на чистом воздухе и включаются на запах
  фрукта, получают выходы детекторов надвигания. Без еды муха как обычно,
  на запах беспокоится, у еды взлетает и не может сесть. `--via input` -
  вместо этого подать запах на сами детекторы (мозг не тронут, убегает
  чётко прочь от еды). Рендер: `--show-smell --inner-max-hz 8`.
- **Алкоголь** - ГАМК сильнее, ацетилхолин слабее. Всё медленнее отвечает на
  угрозу, под конец не отвечает совсем; мозг затихает. Шатает (`--stagger`),
  с половины дозы заваливается на спину.

Медиатор каждого нейрона - из схемы (предсказание FlyWire). Паралич и
шатание добавлены телу отдельно: нейроны модели до паралича не доходят. Доза
для OBS пишется в `output/dose.txt`, по времени - в `ЗАПИСЬ.dose.npz`.

## Проверки

Сервер для них не нужен.

```bash
python tools/smoke_bridge.py            # мост по боевой ветке на заглушке RCON
python tools/smoke_bridge.py --food     # посадка, укусы, еда
python tools/smoke_bridge.py --damage   # удары, гибель, возрождение
python tools/smoke_bridge.py --water    # кругом вода: не садится
python tools/smoke_bridge.py --flood    # после укуса земля стала водой
python tools/smoke_bridge.py --wall     # каменная коробка: застряв, разворачивается
python tools/smoke_bridge.py --steps    # террасы: не душится краем глаз на ходу
```

Смоук проверяет проводку, а не поведение: «не падает, и каждая часть хоть
раз отработала». Поведение проверяет `field_scenarios.py`: настоящий мозг на
ровном поле, фиксированные зёрна, пять сценариев поиска еды (`near`, `last`,
`trap`, `memory`, `lost`), гоночная дорожка `trail` (ломтики в линию до
финиша: `--spacing`, `--length`, `--start-hunger`, `--hunger-minutes`) и
ключи, выключающие правила по одному (`--single`, `--no-search`,
`--no-memory`, `--no-bilateral`, `--no-meal-search`).

Каждый прогон даёт отпечаток - хэш всей траектории. Перед правкой, которая не
должна менять поведение:

```bash
python tools/field_scenarios.py --quick --save output/before.json
# ...правка...
python tools/field_scenarios.py --quick --compare output/before.json
```

Для правок кода, которые не должны менять поведение, -
`compare_loop.py СТАРОЕ_ДЕРЕВО`, где СТАРОЕ_ДЕРЕВО - копия проекта до правки:
мост целиком на подставном сервере с замороженными часами, 15 сценариев
(мобы, еда, вода, стена, террасы, удары с гибелью, голодание, другие тела,
опыты `brain_lab`); всё отправленное серверу, весь вывод и запись мозга
должны совпасть до команды. `--twice` - нынешнее дерево против себя: сверка
повторяема.

Гонка: `smoke_race.py` - три мухи на заглушке целиком: шлюз, телепорты вне
очереди, мухи видят друг друга, общий опрос работает. `check_isolation.py` -
мухи с разными `--name` не трогают тела и счета друг друга и видят друг
друга. `check_shared.py` - отбор мухи из общего снимка гонки совпадает с её
собственными запросами (300 случайных миров, включая случаи, когда снимок
не годится и муха спрашивает сама).

## Ограничения модели

- **Часть мозга.** В схеме 2531 нейрон из примерно 140 тысяч: органы чувств
  и все, кто заметно влияет на нисходящие нейроны побега и руля.
- **Тело.** В данных FlyWire есть только мозг, без брюшной нервной цепочки и
  мышц, поэтому команду нисходящих нейронов в движение переводит декодер:
  разница левой и правой половин задаёт направление, сумма - скорость,
  гигантское волокно - прыжок вверх.
- **Входы.** Частоты сенсорных нейронов задаёт энкодер, поэтому сила всех
  синапсов подобрана при старте одним общим множителем. Точной карты поля
  зрения в коннектоме нет: направления взгляда раздаются зрительным
  нейронам равномерно по своей стороне.
- **Без обучения.** Связи статичны. Голод, рана и память о местах, где муха
  ела, - переменные игры, а поиск еды по запаху - правила поверх мозга:
  фруктовый запах до нисходящих нейронов в этой схеме не доходит.
- **Медиаторы предсказаны.** Знак синапса берётся из предсказанного
  медиатора. У 199 сенсорных нейронов (обонятельные рецепторы и джонстонов
  орган) предсказан не ацетилхолин, хотя первичные сенсорные нейроны
  насекомых холинергические; им знак +1 поставлен явно (поле `sign_forced`
  в схеме).
